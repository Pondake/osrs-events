# Security Policy

## Reporting a vulnerability

Email **dev@absolit.nl**. Please do not open a public issue for a security
problem — an issue is visible to everyone the moment it is filed.

Include what you need to describe the problem: the URL or endpoint, what you
did, what happened, and what you expected. A proof of concept helps. If you
are unsure whether something counts, report it anyway.

This is a hobby project run by one person, so there is no on-call rotation and
no bounty. What you can expect:

- an acknowledgement within a week
- an assessment, and a fix or an explanation of why it is not one
- credit in the release notes if you want it

Please give a reasonable window to fix before disclosing publicly.

## Scope

In scope: this repository, and `osrs-events.com` once it is live.

Out of scope: Old School RuneScape itself and anything run by Jagex, Discord,
and [Wise Old Man](https://wiseoldman.net) — report those to them. Also out of
scope: denial of service, automated scanner output with no demonstrated
impact, and findings that require an already-compromised account or device.

## Supported versions

The `master` branch is what runs in production and is the only version that
gets fixes.
